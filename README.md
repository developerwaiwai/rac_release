# Realistic AXIS Crystallizer（RAC）

**音と映像を、結晶化する。**

RAC（Realistic AXIS Crystallizer）は、録音や再生の途中で埋もれてしまった音の輪郭と「そこに在る」感じを、計算で取り戻すソフトウェアです。AXIS が開発しています。

このリポジトリは RAC の**配布用**です。アルファ版は [Releases](https://github.com/developerwaiwai/rac_release/releases) から無料でダウンロードできます。

> **AIは、作る。AXISは、取り戻す。**

## どんな音になるのか

### 輪郭が締まる
声の子音、弦をはじいた瞬間、ドラムのアタック。音の立ち上がりが、ぼやけずにはっきり聴こえるようになります。ASMR なら、ささやきの「s」や「t」、唇が離れる小さな音が、ひとつずつ分かれて聴こえます。

### 音が、そこに「いる」
ヘッドホンで聴くと、音はふつう「頭の中で鳴っている」か「耳の横から聞こえている」感じがします。RAC をかけると声や楽器の位置がはっきりし、それぞれの音が決まった場所から鳴っているように聴こえてきます。音どうしの境目が分かれて、重なってもつぶれません。

### 何も「足して」いない
RAC は音を描き足しません。新しい楽器が聴こえてきたり、声色が変わったりはしません。**「同じ音なのに、聴こえ方が違う」**——これが RAC の音です。

### 正直に書いておくこと
- **低音が細くなることがあります。** 処理の仕組み上、低い音のエネルギーが少し減るため、それを戻す「低域保護」を入れています。物足りなければ値を上げてください。
- **かけすぎると、ざらつきます。** 「先鋭度」や「強さ」を上げすぎると、高い音がざらざらしてきます。最初は初期値のまま聴いてください。
- **音源によって効き方が違います。** よく録れている音源ほど変化は控えめで、こもった録音や圧縮された配信の音ほど違いが出やすいです。

### 聴き比べのコツ
かけた瞬間は、耳がすぐ慣れてしまうので違いがわかりにくいことがあります。**しばらく RAC をかけたまま聴いてから、Bypass（処理オフ）に切り替えてみてください。** 外したときに音が急に平たく、遠くなったように感じたら、それが RAC の効いていた分です。

## RAC の考え方

### 「作る」のではなく「取り戻す」
いま、音や映像をきれいにする技術の多くは AI を使っています。AI はもっともらしい細部や響きを作って足してくれますが、それは「元々そこにあったもの」ではなく、AI が作ったものです。

RAC は、録音や撮影の時点で確かにそこに在ったのに、劣化によってにじんで埋もれてしまったものを、計算によって元の位置に集め直します。これを「結晶化」と呼んでいます。

### 音のエネルギーは、消えずに移っている
RAC の土台には、二つの考え方があります。

- **音響立方体モデル**：「音の良さ」は、いくつかの軸を持つ立方体のように表せる。
- **音エネルギー保存**：劣化で音のエネルギーは失われるのではなく、本来の場所から周りへ移っているだけである。

移っただけなら、劣化の仕組みを数式で書き表せば、計算で元に戻せるはずです。RAC はこの考えを実装したものです。どちらの考え方も、日本音響学会の研究会で論文として発表しています（下記）。

### いつも同じ結果になる
RAC は推測で音を作らないので、同じ音を同じ設定で処理すれば、いつも同じ結果になります。

### オーディオは、オカルトではない。科学計算だ。
「なんとなく良くなった気がする」で終わらせず、なぜそう聴こえるのかを理論と測定で確かめる。それが AXIS の姿勢です。

## 生まれた経緯

始まりは、壮大な構想ではなく「推しの ASMR を、もっといい音で聴きたかった」という、ごく個人的な動機でした。

1. **ノイズとの戦い**：オーディオインターフェースの出力をワイヤレスマイクの送信機に逆向きにつないだら、盛大なノイズが出た。その原因を一つずつ潰していき、電源の分離・絶縁トランス・マスタークロック・アースまで手を入れて、家庭用の機材で **S/N 比 102.33dB**（重み付けなし）まで追い込んだ。
2. **そこに「いない」**：静かな環境で推しの声を聴くほど、「耳元でささやいているはずなのに、そこにいる感じがしない」ことが気になった。調べると、ケーブルを通るあいだに周波数ごとに音がわずかに遅れる現象（群遅延）に行き着き、それを補正するハードウェアを自作した。
3. **理論へ**：その試行錯誤から、音響立方体モデルと音エネルギー保存の考え方がまとまった。
4. **「似ている」という直感**：音を周波数ごとに分解して眺めているうちに、「この分析のときに音がぼやける仕組みは、録音や再生で音が劣化するときとよく似ている」と気づいた。劣化を数式で書けるなら、失われたものは計算で取り戻せる——RAC はここから始まった。
5. **音から映像へ**：同じ考え方は映像にも当てはまった。映像版を作ってみると効果がはっきり出たため、映像のエンジンも本格的に作った。
6. **8mm フィルム**：そして、実家にあった父の 8mm フィルムの映像も、取り戻すことができた。

推しの声のために始めた寄り道が、何十年も前の家族の記憶にまでつながり、いま、ようやく誰かの手元で鳴る形になりました。

## 既知の制限（アルファ版）

- **Windows 版はコード署名をしていません。** 起動時に「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」で起動できます。Windows 11 の「スマート アプリ コントロール」がオンの PC では、RAC Realtime は起動できません（VST3 版は影響を受けません）。
- **RAC Realtime は音が遅れて出ます。** RAC の処理に加えて、VB-Cable や機器のバッファの分も遅れるため、動画では口の動きと音がずれます。音楽や ASMR を聴く用途に向いています。Mac では、SoundSource などのホストアプリに AU 版を挿してシステム全体にかけると、遅れが映像側で補正され、ずれがほとんどなくなります。
- 詳しくはセットアップガイドの「困ったとき」を見てください。
